XAU/USD Telegram Alert System

What happens from the moment GitHub's timer fires to the message on your phone.

The cast

GitHub ActionsThe alarm clock. Every 15 min (day) and hourly (swing), Mon-Fri, it sends one authenticated request to your app.
Vercel app/api/cron/scan runs the same signal pipeline as the website, then decides whether to alert.
Upstash RedisThe memory. Remembers the last alert (for cooldown) and holds a short lock against double-sends.
Telegram botThe messenger. Delivers the trade idea to your chat.

Security check

Secret compared in constant time. No secret set on the server means everything is rejected. GET returns 405.

Wrong or missing secret: 401, nothing runs

Free checks (no data credits spent)

Config present? Redis reachable? Is gold open (not weekend / 17:00-18:00 NY break)? If ALERT_SESSIONS_ONLY=true, is it 07:00-20:00 UTC on a weekday?

market_closed / outside_session: skipped No Redis: 503, nothing sent

Fetch data and compute in code

3 Twelve Data candle requests, FRED macro, economic calendar. EMA/RSI/MACD/ATR, structure and SMC computed locally.

▼
5

Cheap pre-check before the AI

Hard gates (news within 30 min, stale prices, calendar down in strict mode) or fully mixed trend votes (up = down) skip the AI call and save money.

gate_no_trade / trend_votes_mixed: skipped
▼
6

AI + validation + SMC filter

Model proposes a trade; code verifies every price (stop size, TP1 ≥ 1.5R, TP2 ≥ 2.5R) and SMC may lower confidence.

NO_TRADE: skipped
▼
7

Alert rules (pure code)

Side is BUY/SELL, confidence ≥ ALERT_MIN_CONFIDENCE (60), SMC verdict is not against, and not inside the cooldown (same mode + side, 3 h) unless the entry moved more than 1 × ATR since the last alert.

low confidence / smc_against / cooldown: skipped
▼
8

Lock, re-check, send, remember

Redis SET NX lock (120 s) stops two overlapping runs from both sending. State is re-read, message sent to Telegram, then the entry and time are saved for the cooldown.

duplicate_lock: skipped Telegram fails: 502, lock released, retried next scan sent
